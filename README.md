# Sascha Edney Portfolio

A React portfolio built with Vite and React Router.

## Run locally

Requires Node.js 20.19+ or 22.12+ and npm.

```sh
npm install
npm run dev
```

Open the local URL printed by Vite. The app runs on your computer and does not need to be deployed.

## Production build

```sh
npm run build
npm run preview
```

Page content and project details are in `src/data/portfolio.js`. Static images are in `public/imgs/`.
